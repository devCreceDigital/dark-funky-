# Dark Funky Extremo

Versión rápida y extrema de Dark Funky: The King of Corruption, un juego de ritmo estilo Friday Night Funkin' que se juega en el navegador (también en móvil).

Jugar: https://devcrecedigital.github.io/dark-funky-/

Novedades frente a la versión normal (https://goagentesia.github.io/dark-funky/):
- Dificultad Extremo con notas dobles, notas calavera, notas de cristal, escudos, acelerones y medidor de corrupción.
- Semana Extrema: Sobrecarga y El Rey de la Corrupción.
- Rumi como nueva jugadora.
- Guía e historia al empezar, nombre de jugador, ranking, logros y galería.

El ranking se guarda en el navegador de cada dispositivo.
